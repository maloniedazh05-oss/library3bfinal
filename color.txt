Primary Dark Blue: #0d1b2a → almost navy, for backgrounds and containers

Secondary Blue: #1b3a57 → mid-tone blue, for headers, cards

Accent Blue: #415a77 → lighter blue for buttons or highlights

Highlight/CTA: #778da9 → light blue for text, links, or subtle gradients

Optional Highlight: #e0e1dd → off-white for text contrast
===============================================================================
Color combination suggestions:
A dark blue theme gives a professional, modern, and calming vibe. To make it visually appealing, we need to combine dark, medium, and accent tones, using gradients for depth and hierarchy. This approach will work for containers, headers, backgrounds, and buttons.

Color Palette Suggestion

Primary Dark Blue: #0d1b2a → almost navy, for backgrounds and containers
Secondary Blue: #1b3a57 → mid-tone blue, for headers, cards
Accent Blue: #415a77 → lighter blue for buttons or highlights
Highlight/CTA: #778da9 → light blue for text, links, or subtle gradients
Optional Highlight: #e0e1dd → off-white for text contrast

Gradient Suggestions:

1. Container / Section Background
Use subtle gradients for depth:
background: linear-gradient(180deg, #0d1b2a, #1b3a57);
Effect: Smooth dark → medium blue transition; works for main content areas.

2. Header Background
Headers benefit from slightly lighter top accent to catch attention:
background: linear-gradient(180deg, #1b3a57, #0d1b2a);
Effect: Header stands out subtly but remains cohesive with dark theme.

3. Buttons
Buttons should pop with a clear accent gradient:
background: linear-gradient(135deg, #415a77, #1b3a57);
color: #e0e1dd;
border-radius: 6px;
Effect: Diagonal gradient adds depth, while light text ensures readability.
Alternative gradient for CTA buttons:
background: linear-gradient(135deg, #778da9, #415a77);

Brightens the button for more prominence.

4. Text & Links
Light blues or off-whites for readability:
color: #e0e1dd;  /* main text */
color: #778da9;  /* links or hover states */

5. Accent Elements (cards, hover, borders)
Gradient subtle borders or card backgrounds:
background: linear-gradient(90deg, #1b3a57, #415a77);

Creates depth without overwhelming dark theme.

NOTES:
Contrast: Always check text on dark backgrounds; light text is essential for accessibility.

Gradient direction:
Vertical (180deg) → sections, headers
Diagonal (135deg) → buttons, call-to-action
Horizontal (90deg) → cards, dividers

Limit colors per element: Two-color gradients are enough; more can look busy.
